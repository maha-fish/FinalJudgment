# 终焉裁定

**[English](README.md) | [简体中文](README.zh-CN.md)**

面向 Minecraft 1.20.1 Forge 的创造模式专属神器武器模组。

## 功能

- 创造模式专属神器武器，具有独特的视觉风格。
- 无合成表，仅可从创造模式物品栏获取。
- 多层攻击路径，可绕过绝大多数常规防御。
- 拾取即绑定：无法丢弃，也无法被缴械。
- 可选诊断日志。

## 武器操作

| 输入 | 行为 |
|---|---|
| 左键 | 近战攻击触及范围内最近的有效实体。 |
| 右键 | 范围攻击；扫描附近实体并触发攻击链。 |
| Shift + 右键 | 远程攻击 64 格内的有效实体。 |

每种输入拥有独立的 50 ms 冷却。攻击自动执行多层击杀链。

## 前置要求

- Minecraft 1.20.1
- Forge 47.x

## 安装方式

1. 下载最新的发布压缩包（`.zip`）。
2. 解压压缩包。
3. 将解压出的所有 `.jar` 文件放入 `mods/` 目录。
4. 使用 Forge 1.20.1 启动游戏。

压缩包已包含所有必需组件，无需额外下载。

## 注意

- 武器仅限创造模式获取。在公共服务器中请限制创造模式权限。

## 外部系统交互

启动时，终焉裁定会将内置的运行时组件（Java Agent、原生库、bootstrap jar）从模组 jar 提取到系统临时目录，并加载或注入这些组件。临时文件在游戏退出时删除。不收集、存储或传输任何用户数据。

## 技术说明

- 使用 Forge Coremod、Java Agent、Mixin 和可选的原生支持。
- 所有注入点均在启动日志中可见。
- 采用安全失败设计：某一层不可用时，其余层继续工作。
